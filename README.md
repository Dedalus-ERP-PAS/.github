# .github

Dépôt méta de l'organisation **Dedalus-ERP-PAS**. Il centralise les fichiers de
santé communautaire (community health files) et modèles **par défaut** appliqués
aux dépôts de l'organisation qui ne définissent pas les leurs.

> ℹ️ Ce dépôt doit rester **public** pour que GitHub applique ces fichiers par
> défaut aux autres dépôts (y compris privés) de l'organisation. Un fichier
> présent dans un dépôt donné prime toujours sur son équivalent ici.

## Contenu

| Fichier | Rôle |
|---|---|
| `SECURITY.md` | Politique de sécurité et signalement de vulnérabilités |
| `CONTRIBUTING.md` | Conventions de contribution (branches, commits, PR) |
| `CODE_OF_CONDUCT.md` | Code de conduite (Contributor Covenant 2.1) |
| `SUPPORT.md` | Où obtenir de l'aide |
| `.github/PULL_REQUEST_TEMPLATE.md` | Modèle de pull request par défaut |
| `.github/ISSUE_TEMPLATE/` | Modèles d'issues par défaut (bug, fonctionnalité) |
