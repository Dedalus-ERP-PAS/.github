# Obtenir de l'aide

> Guide de support par défaut pour les dépôts de l'organisation
> **Dedalus-ERP-PAS**. Un dépôt peut fournir sa propre `SUPPORT.md`.

Merci d'utiliser nos projets ! Voici comment obtenir de l'aide efficacement.

## Avant de demander

- Consultez le **`README`** et le dossier **`docs/`** du dépôt concerné.
- Parcourez les **conventions partagées** dans
  [`foundation-skills`](https://github.com/Dedalus-ERP-PAS/foundation-skills).
- Recherchez dans les **issues** (GitHub ou GitLab, ouvertes et fermées) et les
  **tickets Jira** : votre question a peut-être déjà une réponse.

## Où poser votre question

| Besoin | Canal |
|---|---|
| **Bug** (comportement incorrect, erreur) | Ouvrez une **issue** avec le modèle *Signalement de bug* (ou un ticket Jira selon le dépôt) |
| **Demande de fonctionnalité** | Ouvrez une **issue** avec le modèle *Demande de fonctionnalité* |
| **Question d'usage / intégration** | Canal d'échange interne de l'équipe *(à préciser : Teams / Slack)* |
| **Suivi projet / ticket** | **Jira** (`jira.dedalus.com`), projet du dépôt (ex. `HEX`, `PWT`) |
| **Vulnérabilité de sécurité** | **Ne pas** ouvrir d'issue — suivez la [politique de sécurité](./SECURITY.md) |

## Bien rédiger une demande

Pour un traitement rapide, précisez :

- le **dépôt**, la **version / le tag** et l'**environnement** (Production / Test) ;
- ce qui était **attendu** vs. ce qui a été **observé** ;
- les **étapes de reproduction** et, si possible, les messages/logs concernés ;
- une **capture** ou un extrait pertinent.

## Support client / production

Les demandes liées à un **déploiement client en production** relèvent du canal
support Dedalus habituel, et non des issues GitHub.
